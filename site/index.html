Orchestrator, workers, deliveries

One plans. The others build. Hangar checks.

Pin a Claude Code pane as orchestrator: it splits the work into board tasks and starts a worker for each, on a branch of its own in its own git worktree. By default Opus plans, Sonnet works and Sonnet reviews.

A board the agents share

Tasks with the files they own and what they depend on, claimed atomically over MCP. Hangar never runs two tasks at once whose files overlap.

Every delivery is checked before it lands

A finished worker hands in its branch. Hangar merges it in a scratch worktree, runs your check command and has a reviewer agent read the diff. A step that fails goes back to the worker.

Delivery of #t3 Recipe page
  1. Merged onto main in a scratch worktree Your checkout is left alone until the fast-forward.
  2. pnpm test passed The check command you set, run by your shell.
  3. Review approved A reviewer with a fresh context, read-only tools.
  4. Landed: main fast-forwarded Local only. Nothing is pushed.

Hangar never pushes

Merges are local fast-forwards. Pushing, pull requests and releases stay your call.

Woken by events

The orchestrator rests while workers run; Hangar wakes it when a task moves or a delivery lands or fails.

Rules a prompt can't bend

Permissions, the check command and the branch work lands on are set per workspace and enforced by Hangar.

Hangar Mobile

Answer your agents from your phone.

See what waits for you in every project, answer Claude's questions with a tap, allow or deny a permission. Hangar serves the app itself, over your own Tailscale network: no app store, no account, no server of ours.

Hangar Mobile running on sample projects.

Private, through Tailscale

Hangar Mobile listens on 127.0.0.1 only: Tailscale, a free app that links your own devices, is the only way in, over HTTPS. Each phone pairs with a one-time code. Notifications reach it even with the app closed, sent by your PC.

Set up in about a minute

  1. Install Tailscale on the PC and the phone, on the same account.
  2. In Hangar, Settings › Mobile: turn on Hangar Mobile, then HTTPS access.
  3. Scan the QR code, add Hangar to the Home Screen.

Nodes: Hangar on another machine

Add a Linux machine you reach over SSH: Hangar installs a headless hangar-node, starts it and keeps a tunnel to it. A workspace can live there, its terminals, Claude Code and board included, and the window shows it like a local one.

Or send one worker to the node for a heavy build or a GPU box: its branch comes back to be checked, reviewed and landed here.

Questions

What does it cost?

Nothing: Hangar.AI is MIT-licensed, with no account and no paid tier. The agents cost what they already cost you, on your own plan or API key. An orchestrator, its workers and a reviewer run at once, so they use a plan's limits faster than a single agent.

Does it work with my Claude Pro or Max plan?

Yes. Hangar starts the claude you installed, with the login it already has, and never asks for your credentials. The navigator shows your plan's five-hour and weekly usage.

Does my code or data leave my machine?

Not through Hangar: no server, no telemetry. The board lives in your project (.hangar/board.json); memory, settings and statistics stay in the app's data folder. Hangar goes online to check GitHub for updates, for the dictation model or Groq if you turn them on, and for Hangar Mobile's notifications once you enable them.

Will the orchestrator push to my repository?

No. Workers commit on branches of their own, and a delivery lands on yours as a local fast-forward. Hangar never pushes, opens a pull request, tags or deploys, and its agents are told not to either.

Why does Windows warn me about the installer?

It is not code-signed yet, so SmartScreen warns the first time: choose More info, then Run anyway. The installer is built by GitHub Actions from the public source.

What does Hangar Mobile need?

Hangar open on a PC that stays on, and Tailscale on the PC and the phone, on the same account. On an iPhone, notifications need iOS 16.4 or later and the app opened from the Home Screen. Merging a delivery is still done on the PC.

Where do I ask a question?

On the Discord. Bugs and requests go to GitHub issues.
